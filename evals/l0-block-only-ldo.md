# 5V→3.3V LDO 电源模块设计要求

> L0 取证专用(block-only 基线;非金标 eval,不进 evals/requirements/ 金标集)

## 功能

- 5V 输入经 **AMS1117-3.3** 线性降压出 3.3V,负载 ≤500mA
- 输入侧去耦 10µF + 100nF,输出侧去耦 22µF + 100nF
- 电源经网标签(5V / 3V3 / GND)引出,不用连接器,单页原理图

## 网络

- 5V / 3V3 / GND 齐全

## 约束

- 纯上游块组合(ldo-ams1117-3v3),不走自由拓扑分解
- 无 MCU、无指示灯、无测试点,保持最小块拓扑
