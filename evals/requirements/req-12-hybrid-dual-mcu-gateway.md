# STM32 + ESP32 双核网关板设计要求（自写 · 混合）

> 金标准 eval v0 · 需求样本 12
> 难度层：困难（v2 重设计 2026-08，26→14 分层）；原编号 05
> 来源：自写（混合板：MCU×2 + 电源 + 通信 + 存储）。考察块：STM32 最小系统 / ESP32 模组 / 双电源域 / UART 桥 / USB 串口 / EEPROM / SWD。

## 设计规格（客户口吻）
- **层数**：4 层板（SIG/GND/PWR/SIG），无线部分和 MCU 部分分区布局
- **丝印**：完整丝印，板名 `GW-DUO-01` + 版本号

## 主控架构
- **实时侧**：STM32F103C8T6（LQFP-48），负责采集和控制
- **联网侧**：ESP32-S3-WROOM-1，负责 Wi-Fi/BLE 上报
- 两片之间 **UART 互联**（交叉连接，115200 默认），另加 2 根握手线（BOOT 互控/复位互控）

## 供电与电源
- **USB-C** 5V 输入 + **5V 端子**备用（共用一路，防倒灌）
- 5V → 3.3V 用 **AMS1117-3.3**，两片 MCU 共用 3V3，按两片峰值电流算裕量
- 复位按键 ×2（各自 MCU 一个）+ BOOT 按键 ×1（ESP32）

## 下载与调试
- 板载 **CH340N** USB 转串口，通过跳线/模拟开关选择接 STM32 或 ESP32 的烧录口（写明切换方案）
- STM32 预留 **SWD 4-pin 排针**（3V3/SWDIO/SWCLK/GND），丝印逐脚标注

## 存储
- 一片 **24C02 EEPROM**（I2C，挂 STM32），写保护接地
- 预留 SD 卡焊盘（可选，本版可不贴）

## 指示灯
- **红色**：电源
- **绿色**：STM32 心跳（GPIO）
- **蓝色**：ESP32 状态（GPIO）
- 所有 LED 附近丝印 **+** / **−**

## 结构固定
- 四角 **M3 螺丝孔** ×4
- ESP32 天线伸出板边或下方禁铜

## 其他要求
- 双 MCU 晶振各自独立，下方禁走线
- USB 差分对 90Ω
- 符合电气规范，复位电路按各自 datasheet 建议（100nF+10K）
