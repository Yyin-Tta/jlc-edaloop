# 设计评审报告(critic,弱门禁)
评审对象: 20 blocks, status=PASS

- [CRITIC_INTERFACE_PROTECTION@ch340n1] CH340N 的 USB 差分数据线未绑定:ports_binding 中缺少 UD+/UD- 到 USB_DP/USB_DM 的连接,USB-C 只做了电源入口,串口通路实际断开。 | 建议: 为 ch340n1 补充 USB_DP/USB_DM 端口绑定(UD+→USB_DP,UD-→USB_DM),并注意 90Ω 差分阻抗与长度匹配。
- [CRITIC_PULL_RESISTORS@mcu1] BOOT0 网络同时绑定到 pin12(PA2)与 pin44:STM32F103C8 LQFP48 中 BOOT0 仅在 pin44,pin12 是 PA2,且 PA2 与 BOOT0 短接会破坏该通用 IO 并可能导致下载模式逻辑异常。 | 建议: 删除 pin12 对 BOOT0 的绑定,BOOT0 只接 pin44(经 10k 下拉接 GND,按键切到 3V3)。
- [CRITIC_POWER_INTEGRITY@rs485_1] rs485_1 选用的块为 max485(5V 器件),但电源端口绑定到 3V3 轨;MAX485 无 3.3V 版本,3.3V 供电超出其规格且 DI/DE 逻辑电平与 3.3V MCU 不兼容风险高。 | 建议: 改用 SP3485/MAX3485 等 3.3V 收发器块,或将该块电源改绑 5V 并在 RO/DI/DE 与 MCU 之间加电平转换。
- [CRITIC_THERMAL@ldo1] sizing 给出 ldo1 结温估算 Tj≈136°C、裕量 -30°C,AMS1117 在当前工况下热设计不满足要求(板级设计层缺陷,非单纯取值问题)。 | 建议: 更换为效率更高的 BUCK(如 MP1584/TPS54331)或降低负载电流,并为 LDO 增加铺铜散热面积后重新核算结温。
- [CRITIC_DECOUPLING@r_led_pwr] 三个 LED 限流电阻取值 120Ω,与 sizing_recommendations 给出的 270Ω(E24)明显不符(120Ω 时 LED 电流约 14mA,超出建议设计点近一倍)。 | 建议: 将 r_led_pwr/r_led_hb/r_led_bus 的 value 改为 sizing 建议的 270Ω,或给出明确出处说明为何偏离。

(以上为 warn 级建议,不阻断交付;采纳与否人工决定)
