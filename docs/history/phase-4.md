### Phase 4(原理图质量与电气正确性,2026-08-21 规划,ADR-0010)

**范围决议**:Phase 3 打通「脑洞→下单」全链,但各段**质量深度**不足——布局是防重叠优先的顺序填格(无分区/页面几何开环/无可读性件),电气正确性只到「轨名在场」层(电压兼容/电流预算/阻容核对零实现),需求侧电参数无结构化表达,知识侧电气数据只写不读。Phase 4 定位**质量深耕**:把「画得对」升级为「画得好+证明合适」,聚焦四重点——**F1 需求识别质量 / F2 知识检索完备 / F3 原理图布局质量(用户明示最高优先:合理紧凑、按功能分块、不重叠) / F4 电气与功能正确性(电压、电流满足芯片需求,阻容参数合理,功能符合需求)**。全部批次 Go 指标可机械评测(原则 2/5);金标准口径更新为 **26 需求**(evals/requirements 现有 req-01..23+25/26/27,req-24 为 .bak 不入 glob)。
