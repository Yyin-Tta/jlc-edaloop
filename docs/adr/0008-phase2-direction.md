# Phase 2 方向论证

> 状态:论证稿(2026-08-20)。供评审;决策后拆里程碑进 DEVELOPMENT.md §9。
> 背景:v0.2.0 已达成 Phase 1 全部验收线(22/22=100%、95 块、中位 1 轮、开源发布)。

## 候选方向(来自 §9 Phase 2+ 与三份调研)

| 方向 | 一句话 | 论证 |
|---|---|---|
| A 自由拓扑生成 | 目录无块时,LLM 直接生成器件级拓扑+网表 | **中期**;见下 |
| B 参数 sizing | 电感/电容/电阻值按工况计算(增益/带宽/纹波) | 调研已论证(ORACLE/LLM-USO),先做**规则子集** |
| C BOM 成本优化 | 同功能块多选一,按 LCSC 价格/库存打分 | 数据已有(块库全带 C 号),**最便宜** |
| D 多页大原理图 | 20+ 块设计分页+分区(上游 zone 体系已就绪) | 需求出现时做 |
| E KiCad 后端 | 第二落图后端 | 生态加分项,非核心;**缓** |

## 排序建议:A(子集) → C → B(子集) → D → E

### A. 自由拓扑生成(受控子集)

**为什么现在做**:超纲需求(CAN/OLED/热电偶)在补块前只能 uncovered;但长尾器件永远补不完。当前 place 通道已有"库外器件落图"能力(lib search→place→autoconnect),缺的只是**拓扑决策**(器件选型+连线)。

**受控子集定义(v1)**:
- 触发条件:planner 对某功能 uncovered **且** 该功能可分解为 ≤5 个已知库内器件(分立/接口);
- 生成方式:LLM 基于器件 pinout(库内已有 95 块的全量 pinout)产出 pins_binding 级拓扑,复用 place 通道落图;
- 门禁:现有强门禁全套(gate+pin 回读+substance)+ 新增"拓扑 sanity"(电源轨连通性:每个 VDD 有来源、GND 共地)。

**不做**(v1):运放负反馈网络/补偿网络等模拟拓扑——参数敏感,sizing(B)成熟前自由生成必错。

**预估**:2-3 周(规划器 prompt 扩展+拓扑 sanity 门禁+10 个冷门器件 eval)。

### C. BOM 成本优化

**为什么排第二**:基础设施全在——块库 95 个 lcsc 号、`lib search` 可查价格库存、BlockPlan 已有多实例概念。只差:检索层加"价格/库存权重"、planner 加成本预算参数、交付 BOM 带成本汇总。
**预估**:1 周(纯软逻辑,无真机风险)。

### B. 参数 sizing(规则子集)

**子集**:三类高价值公式——①LDO/BUCK 输出入电容(纹波+瞬态);②LED 限流(已有 desc,公式化);③分压网络(反馈/检测)。
**为什么缓**:需求文档里出现"sizing 要求"的频率低;且 desc 里已含典型值,先把 A 做完看真实需求。
**预估**:1-2 周(公式库+datasheet 建议提取联动)。

### D/E. 缓

多页在单页 30+ 块出现真实拥挤时启动(上游 zone-plan/zone-draw 已备);KiCad 等 v0.3 社区反馈。

## 风险与对策

| 风险 | 对策 |
|---|---|
| A 的幻觉拓扑 | pinout 全部来自库内回读(ground truth),拓扑 sanity 门禁兜底;失败即 uncovered 回退 |
| C 的价格数据时效 | LCSC 实时查询(ADR-0004 通道),不缓存长期 |
| 带宽(单人) | A/C 并行推进会稀释;按 A→C 串行 |

## 建议决议

Phase 2 = **A(自由拓扑受控子集,2-3 周) + C(BOM 成本,1 周)**,B 按需插入,D/E 挂起。
