# 调研:国产 EDA Agent 化现状、政企需求与国外发展对比

- **日期**:2026-08-17
- **性质**:产业/政策面调研(配合 `research-vision-v2-feasibility.md` 技术面)
- **信息来源分级**:🟢 一手网页验证(本次/前次调研抓取) / 🟡 知识库信息(未经本次在线核实,搜索引擎污染导致部分中文信源无法访问)
- **结论速览**:国外已进入"agent 工作流编排"产品化阶段(Synopsys AgentEngineer、Cadence AI 套件);国产芯片级 EDA 龙头尚未公开 agent 产品,**唯独嘉立创 EDA(板级)生态 agent 化最活跃且官方开放**;政策端(出口管制倒逼 + 大基金三期 + 信创)构成明确的国产替代刚需窗口。

---

## 1. 国外发展现状:从"AI 优化"到"Agent 编排"三阶段

### 1.1 阶段演进时间线

| 阶段 | 时期 | 代表产品 | 本质 |
|---|---|---|---|
| ① 单点 AI 优化 | 2020–2023 | Synopsys DSO.ai(2020,首个商用 RL 版图优化)、Cadence Cerebrus 🟡 | 强化学习优化既定流程的 PPA,人类仍逐步操作 |
| ② Copilot 副驾 | 2023–2025 | Synopsys.ai 套件(2023-03 发布)+ Copilot、Cadence Copilot(与 NVIDIA 合作)🟡、西门子 EDA AI 助手 🟡 | GenAI 对话式嵌入工具链,文档问答/脚本生成 |
| ③ **Agent 编排** | 2025–2026 | **Synopsys AgentEngineer** 🟢、Flux.ai steerable agent 🟢、Quilter 全自动布局 🟢 | 多 agent 自主规划-执行-校验,human-in-the-loop 检查点 |

### 1.2 Synopsys AgentEngineer(国外 agent 化旗舰,官网一手信息 🟢)

- **定位**:"Re-engineer Engineering"——编排式多 agent AI 工作流,宣称**最高 20x 生产力提升**;
- **能力**:自然语言 spec → RTL 生成、验证规划、testbench 创建;agent 可 reason/plan/learn/execute,单兵或团队协同;
- **L1–L5 自主性分级框架**:L1 基础辅助 → L2–L4 协作式部分自主 → L5 高度自主(对标自动驾驶分级,是行业首个明示的 agent 成熟度路线图);
- **生态**:2025-12 与 NVIDIA 战略合作(硅设计+制造 agent 化);与 Microsoft 联合云上 AI 芯片设计;已完成 Ansys 收购(多物理场融合);
- **注意**:Synopsys 的 agent 主战场是**芯片级(数字/验证/测试)**,非板级/原理图。

### 1.3 其他国外玩家

| 玩家 | 领域 | 状态 | 来源 |
|---|---|---|---|
| Cadence | 芯片+板级 | Cadence 25.1(2025-10)OrCAD X/Allegro X AI 加持;Cerebrus/JedAI 平台化 🟡 | 知识库+间接证据 |
| Flux.ai | **板级/原理图** | Copilot、Knowledge Base、self-correcting agent、steerable agent、MCP server($37M 融资)——**与本项目愿景最直接竞争** | 🟢 前轮调研一手 |
| Quilter | 板级 PCB 布局 | 物理仿真 + RL 全自动布局,数小时返回多个可制造候选 | 🟢 前轮调研一手 |
| Jitx / CircuitMind | 代码生成硬件 / AI 选型 | 细分单点 | 🟡 |

**小结**:国外"芯片级 agent"与"板级 agent"双线并进;芯片级由三巨头把持(闭源、天价License),板级由创业公司(闭源 SaaS)跑马圈地。**开源 + 可私有部署的板级 agent 是全球性空白。**

## 2. 国产 EDA Agent 化现状:三个梯队

### 2.1 梯队划分

| 梯队 | 代表 | Agent 化程度 | 证据 |
|---|---|---|---|
| **芯片级龙头** | 华大九天、概伦电子、广立微、芯华章 | **无公开 agent 产品**;AI 叙事停留在"仿真加速/良率优化" | 🟢 华大九天官网全量浏览:产品栏(模拟全流程/存储/射频/平板显示/数字/晶圆制造/先进封装)**无任何 AI/agent 产品项**;2025-10 生态大会主题"科技·人文",新闻聚焦教材进高校与客户案例 |
| **板级/中小用户** | **嘉立创 EDA(EasyEDA Pro)** | **国产唯一官方推动 agent 生态的 EDA** | 🟢 前轮调研一手:官方开源 eext-easyeda-api-agent(DeepSeek 自然语言/语音调 eda.* API)、extension-dev-skill(Agent 开发扩展的 Skill 包)、extension-dev-mcp-tools(Agent 自动调试 MCP)、eext-datasheet-helper(本地 OCR);社区 easyeda-agent(229★)等 30+ 仓库 |
| **学术侧** | 北大、港中文、东南等 | 论文密集产出 | 🟢 arXiv 一手:AnalogXpert(北大 Yibo Lin 组)、ChatEDA(港中文 Bei Yu 组)、多篇 ISEDA 2025 论文(东南 Jun Yang 组)——**国内高校在 LLM+EDA 学术产出全球占比很高,但产业转化弱** |

### 2.2 关键判断

1. **国产芯片级 EDA 的 agent 落后国外约一个阶段**(处于"单点 AI 优化/试点"对应国外 2020–2023 水平),主因:工具本身与三巨头有代差、客户(军工/大 IC 厂)对可靠性要求极高、AI 投入优先服务于流程补全而非交互革命;
2. **嘉立创 EDA 是异类**:因其官方开放扩展 API(`eda.*` 86 命名空间)+ 插件市场 + 免费策略,agent 生态自发繁荣——**这是本项目选择嘉立创生态的根本产业依据**;
3. 国产厂商的 AI 能力建设多为"内部提效"叙事(如仿真器加速),未到"用户可用的 agent"产品化;🟡 概伦/芯华章有 LLM 相关演示传闻,未获一手证实,存疑待核。

## 3. 政企需求分析

### 3.1 政策与安全驱动(确定性高)

| 事件 | 时间 | 影响 |
|---|---|---|
| 美对华 EDA 出口管制(首先针对 GAAFET 先进工艺) 🟢公认事实 | 2022-08 | 国产替代上升为国家战略 |
| Synopsys 对华"断供—恢复"风波(BIS 短暂停发许可后恢复) 🟡知识库 | 2025-05~07 | 供应链安全焦虑到达顶点:头部 IC 公司加速引入国产 EDA 做"二供" |
| 大基金三期成立(注册资本 3440 亿) 🟢公认事实 | 2024-05 | 明确投向设备、材料、EDA 等卡脖子环节 |
| 信创/国产化目录推进 🟡 | 持续 | 党政/军工/央企体系内,EDA 国产化采购有强制/加分属性 |
| "十四五"将 EDA 列为核心攻关 + 一流高校设集成电路学院/EDA 教材本土化(华大九天教材已进高校 🟢官网) | 持续 | 人才与标准长期布局 |

### 3.2 需求主体分层

| 主体 | 核心诉求 | 对 agent 的具体需求 | 付费意愿 |
|---|---|---|---|
| **军工/航天/政府研究所** | 安全可控、私有部署、审计留痕 | 全离线(本地 LLM)、操作可回放、权限门禁 | **高**(安全预算) |
| 大中型 IC/系统公司 | 二供避险、降本增效 | 国产 EDA 具备与主流流程的互操作性;agent 提效但需可靠性证明 | 中高 |
| **中小硬件公司/方案商** | 快速打样、压缩研发成本 | **"需求→原理图"自动化**正是最大痛点:缺资深硬件工程师,养不起完整硬件团队 | 中(基数大) |
| 高校/职校 | 教学与科研 | AI 辅助教学、国产工具链实训 | 低(靠补贴/采购) |
| EDA 厂商自身 | 补齐工具代差 | agent 层可"绕过"单点工具差距,直接在新范式竞争 | 潜在合作方 |

### 3.3 人才缺口(🟡 行业常引估算)

中国 EDA 从业人员约数千人量级,缺口常被引述为"现存 2 倍以上";硬件工程师(板级)缺口更大且分布在中长尾企业——**这正是"原理图设计 agent"的需求基本盘:用 AI 填补中长尾企业的资深工程师缺口**。

## 4. 机会窗口判断(结合前两轮技术调研)

```
国外芯片级 agent(Synopsys/Cadence)  ████████████ 已产品化,但被管制/天价/闭源
国外板级 agent(Flux.ai/Quilter)     ████████     闭源 SaaS,海外供应链,数据出境
国产芯片级 EDA agent                 ██           基本空白(工具代差期)
国产板级 EDA agent(嘉立创生态)      ████         生态自发繁荣但无整合性闭环产品
                                          ▲
                                    本项目切入点:
                          开源 + 本地部署 + LCSC供应链 + 校验闭环
```

**四个确定性趋势的交汇**:
1. 政策端:管制倒逼 + 大基金三期 → 国产 EDA 替代刚性预算存在;
2. 供给端:嘉立创官方开放扩展 API/插件市场 → 唯一可做 agent 的国产开放平台;
3. 技术端:LLM 电路生成学术成熟(AaLLM/AnalogXpert 等)+ 校验门禁模式已被 easyeda-agent 验证;
4. 竞争端:Flux.ai 证明了商业可行性但**不做开源/中国供应链/私有部署**;国产芯片级厂商短期无暇顾及板级 agent。

**风险**:嘉立创官方自身若下场做整合 agent(它已有个例组件);Flux.ai 若开放中国区;芯片级厂商若下沉。窗口期估计 1–2 年。

## 5. 对本项目的行动建议

1. **站位**:做嘉立创生态的"agent 中间层"(上游接需求/BOM/datasheet,下游复用 easyeda-agent 门禁),不与官方插件、社区 CLI 重复;
2. **合规即卖点**:本地 LLM 选项 + 全程审计日志 + 校验门禁 → 直接对齐军工/研究所/央国企采购画像;
3. **叙事对齐政策**:项目文档/申报材料可挂靠"国产 EDA 智能化""AI+集成电路攻关"话语体系(大基金三期、信创);
4. **验证国产大模型**:DeepSeek(嘉立创官方扩展已用)→ 顺势支持,降部署门槛;
5. 补调研项(后续):概伦/芯华章/广立微 2025–2026 AI 动态(需人工翻年报/投资者关系记录,搜索引擎不可达);Cadence/Siemens 2026 agent 产品细节(官网 403,需换渠道)。
