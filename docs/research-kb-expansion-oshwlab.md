# 块库扩容调研:oshwlab 复刻路线(53→100)

> 状态:调研笔记(2026-08-19)。结论先行:**不建议自动化爬取,建议"主题清单 + 人工策展 + 复用现有提取管道"的半自动路线。**

## 1. 现状与目标

- 当前 53 块(20 策展 + 12 分立回读 + 22 上游映射);Phase 1 目标 100。
- 候选源:oshwlab 开源广场(数万工程,SPA 渲染)、easyeda-agent 上游块库(已映射 32/37)、LCSC 应用笔记。

## 2. oshwlab 可行性评估

| 通道 | 现实情况 |
|---|---|
| 网页抓取 | SPA,内容经 JS 动态加载;`webfetch` 只能拿到壳与导航,无工程数据 |
| 公开 API | 站点无文档化开放 API;工程详情接口需登录态/鉴权(未验证反爬边界) |
| 工程文件 | 单工程可导出 JSON(EasyEDA Pro 源文件),但需逐工程人工下载 |
| 大洋彼岸的教训 | M2 边界明确"不做在线爬虫"(§5.2);合规与稳定性都不支持 |

**结论:oshwlab 适合作为"选型参考目录"(人看),不适合作为自动化数据源(机器拉)。**

## 3. 推荐路线:主题清单 + 半自动策展

1. **缺口分析**(可自动化):对 evals 需求与既有 53 块做覆盖矩阵,列出 uncovered 高频类目。
   已知缺口(来自 W3/W4 运行记录):CAN 收发(SN65HVD230)、以太网(PHY/HR911105A)、电机驱动(DRV88xx/AIN2)、锂电保护(DW01+8205)、USB-HUB 外围、LDO 其他压差(3V3 外:1.8V/5V→3.3V 大电流 TPS7xx)、RGB LED(WS2812)、RTC(DS3231)、水位/土壤等传感器前端。
2. **人工选型**:在 oshwlab/LCSC 按类目挑 1-2 个高星工程作拓扑参考(人工打开网页)。
3. **半自动入库**(管道已有):
   - 分立器件:`lib search` → `sch place` → `sch read` 回读 pinout(批量脚本已验证,12 器件/轮);
   - 组合功能块:先 `edaloop ingest` 提取核心 IC 引脚表,再人工写 ports_binding 契约(参考 PC817/B0505S 块的写法);
   - 上游块库季度同步:easyeda-agent 新 release 时重跑 `dump_upstream.py` 增量映射。
4. **验证门禁**:每批新块抽样真机 `block-apply` + `sch gate`(P1 三批已示范)。

## 4. 优先批次建议(每批 ~12)

- 批 A(电源补全):DW01+8205 保护 / TPA3116 / MP1584 / RT9193-1.8V / 保险丝座 / 电池座 18650 / CR1220 座
- 批 B(通信补全):SN65HVD230 / HR911105A 网口 / SIM800 模组座 / MAX3232 / CH9350 键鼠
- 批 C(人机交互):WS2812 / DS3231 / 0.91 OLED 座 / EC11 编码器 / 蜂鸣器 / 触摸 IC(TTP223)
- 批 D(传感):DS18B20 / DHT11 座 / 声音 MIC / 光敏 / 土壤湿度 / 人体 PIR

预估:4 批 × 12 = 48 新块 → 53+48 ≈ 100 达标。
